# CodeThoth Support & Feedback Tracker

Welcome to the official support and feedback portal for **CodeThoth** — the native macOS developer utility for precise AI context assembly.

## 🚀 Quick Links
- **Official Website**: [https://codethoth.app](https://codethoth.app)
- **Mac App Store**: [Download CodeThoth](https://codethoth.app)

---

## 💬 How to Get Help or Share Feedback

### 1. Report a Bug or Issue
If you encountered a crash, UI glitch, or parsing error:
- Search existing [Issues](https://github.com/eddywen/CodeThoth-Support/issues) to see if it has already been reported.
- If not, [Open a New Bug Report](https://github.com/eddywen/CodeThoth-Support/issues/new/choose).

### 2. Request a Feature & Discussions
Have an idea for a new template, language AST support, or want to discuss workflows?
- Start a conversation in [Discussions](https://github.com/eddywen/CodeThoth-Support/discussions).
- Submit a [Feature Request](https://github.com/eddywen/CodeThoth-Support/issues/new/choose).

---

## 🔒 Privacy & Local Safety
CodeThoth operates **100% locally on your Mac**. No source code, project directory structure, or prompts are ever collected or transmitted to external servers.
